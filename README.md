# Дозатор

Настольное приложение на Electron для клинических расчётов и оформления рецептов.
Работает без интернета, ничего никуда не отправляет, все данные остаются в окне приложения.

## Что внутри

| Раздел | Что считает |
|---|---|
| Концентрация | % ↔ мг/мл ↔ 1:X, содержание вещества в ампуле |
| Доза и объём | разовая и суточная доза по мг/кг, объём в мл, число ампул, контроль максимума |
| Международные единицы | инсулин U-100/U-40, гепарин, окситоцин; МЕ ↔ мкг для витаминов A, D, E и пенициллина |
| Разведение | C₁V₁ = C₂V₂, сколько взять концентрата и сколько добавить растворителя |
| Инфузия | мл/ч из мкг/кг/мин, капли в минуту, скорость капельницы |
| Дети | площадь тела по Мостеллеру, поддерживающая инфузия по правилу 4-2-1, доза на м² |
| Рецепт | пропись Rp. / D.t.d. / S. на латыни, несколько прописей в бланке, копирование и печать |

## Запуск

Нужен Node.js 18 или новее — https://nodejs.org

```bash
npm install
npm start
```

## Сборка установщика для Windows

```bash
npm run dist
```

Готовые файлы появятся в папке `dist`:
* `Dozator Setup 1.0.0.exe` — обычный установщик;
* `Dozator 1.0.0.exe` — портативная версия, запускается с флешки.

Собирать лучше на самой Windows. Из Linux тоже можно, но потребуется Wine.

## Как править

Весь интерфейс и все формулы лежат в одном файле `src/index.html` — разметка, стили и скрипт.
Чтобы добавить препарат в справочную таблицу или новый коэффициент МЕ, достаточно дописать
строку `<tr>` или `<option>` в этом файле. Пересобирать ничего не нужно, хватит `Ctrl+R` в окне.

## Формулы, которые используются

* 1 % = 10 мг/мл; раствор 1:X = 1000/X мг/мл
* объём = доза (мг) ÷ концентрация (мг/мл)
* C₁·V₁ = C₂·V₂
* скорость (мл/ч) = доза (мкг/кг/мин) × масса × 60 ÷ концентрация (мкг/мл)
* капли/мин = объём (мл) × капель в 1 мл ÷ время (мин)
* площадь тела (м²) = √(масса × рост ÷ 3600)
* поддерживающая инфузия: 4 мл/кг/ч на первые 10 кг, 2 мл/кг/ч на вторые 10 кг, далее 1 мл/кг/ч

## Важно

Программа — вспомогательный инструмент арифметики, а не источник назначений.
Ответственность за дозу, путь введения и совместимость препаратов несёт врач.
Результат расчёта проверяйте по инструкции к препарату перед введением.
